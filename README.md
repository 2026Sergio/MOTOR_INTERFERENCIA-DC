# Sistema Experto para Diagnóstico de Computadoras

## Descripción

Este proyecto consiste en un sistema experto desarrollado en Python para diagnosticar problemas comunes en computadoras mediante reglas de conocimiento y un motor de inferencia.

El sistema analiza los síntomas ingresados por el usuario y genera diagnósticos junto con recomendaciones basadas en el conocimiento almacenado.
